# Images are stored locally, and source images are never redistributed

A recipe's photograph is downloaded and kept on the device, because offline use is a
requirement and a remote image breaks it. Unlike ingredients and method, photographs
genuinely are protected by copyright, so the copy relies on the French private copy
exception in article L122-5, which covers reproductions from a lawful source, strictly for
the private use of the person making them and not for collective use.

## Consequences

Two classes of image exist and they are not interchangeable. A source image came from
someone else's page: it stays on the device, it is included in the user's own Export
because that is still private use, and it is excluded from anything sent to another
person. A user image is a photograph the user took of their own cooking: it belongs to
them and carries no restriction.

Any feature that would upload, host or share a source image is outside the exception and
must not be built. The absence of a server, per ADR-0001, already makes this hard to do by
accident, which is a happy side effect rather than the reason.
